# Deekshith Reddy — Cybersecurity Research Lab Portfolio

A responsive, single-page portfolio built with React, Vite, Tailwind CSS and Framer Motion.

## Run locally

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

The production-ready site is generated in `dist/`.

## Personalize before publishing

Search `src/App.jsx` for `YOUR_` and replace:
- `YOUR_EMAIL@example.com`
- `https://github.com/YOUR_GITHUB`
- `https://www.linkedin.com/in/YOUR_LINKEDIN/`

Also update:
- Project repository/demo links once they exist.
- Internship dates and your exact individual responsibilities.
- Certificate verification URLs.
- Project statuses and descriptions to match the actual implementation.
- Add screenshots and evidence for completed projects.

## Deploy

You can deploy the `dist/` folder to Vercel, Netlify, Cloudflare Pages or another static hosting provider. For Vercel, connect the repository and use:
- Build command: `npm run build`
- Output directory: `dist`

The contact section currently uses a `mailto:` link. A production contact form requires a backend or trusted form service; do not put private API keys in frontend code.
